تفويض حساب Google

مطلوب مرة واحدة قبل التفويض

  1. تفعيل Google Drive API في مشروع Google Cloud.
  2. إنشاء OAuth Client من نوع Web application وإضافة رابط الرجوع المطابق.
  3. تحديد بريد المسؤول وإدخال بيانات OAuth محليًا في .env.
  4. التأكد أن مجلد Drive خاص، وأن حساب المسؤول يستطيع إضافة الملفات إليه.

لا تُرسل Client Secret أو مفاتيح التشفير إلى المحادثة ولا تضعها في ملفات الواجهة.
